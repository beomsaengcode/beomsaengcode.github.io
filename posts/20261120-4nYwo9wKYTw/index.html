3 ways to shrink chat history (and your LLM API bill)

LLM API는 앞 대화를 기억하지 못해서 매번 대화 전체를 다시 보내요(장애 일지 #2). 그래서 대화가 길수록 요금이 계단처럼 올라요. 줄이는 법 3가지, 저장해 두고 상황에 맞게 고르세요.

1. 자르기 (truncation, sliding window): 최근 N턴만 보낸다. 가장 간단하지만 앞에서 정한 조건까지 사라질 수 있음

2. 요약 (summarization): 오래된 대화는 요약 한 덩어리 + 최근 몇 턴. 흐름은 남지만 요약할 때 호출이 한 번 더 듦

3. 프롬프트 캐싱 (prompt caching): 내용은 그대로, 똑같은 앞부분은 서버가 저장해 둔 걸 다시 씀. Anthropic 공식 가격 기준 캐시 읽기는 기본 입력 값의 1/10 이하(모델마다 다름). 앞부분이 바뀌면 캐시가 깨지니 고정할 건 앞에

셋은 같이 써도 돼요. 예: 시스템 프롬프트는 캐싱, 아주 오래된 대화는 요약
