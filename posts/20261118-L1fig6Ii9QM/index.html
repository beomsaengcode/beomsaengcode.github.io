대화가 길수록 API 요금이 계단처럼 오른 이유 · 장애 일지

Why your LLM API bill climbs like stairs · Incident log #2

챗봇을 열었더니 대화가 길어질수록 API 요금이 계단처럼 올랐어요.

LLM API는 앞 대화를 기억하지 못해서, 요청마다 지금까지의 대화 전체를 다시 보내요. 주고받는 양이 같다고 치면 10번 대화하는 동안 보내는 입력은 처음의 10배가 아니라 55배(1+2+…+10)예요.

해결 1. 오래된 대화는 요약 한 덩어리로 줄여서 보낸다.

해결 2. 프롬프트 캐싱. 앞부분이 똑같으면 서버가 저장해 둔 걸 다시 쓰고, Anthropic 공식 가격 기준 캐시에서 읽은 입력은 기본 입력 값의 10분의 1 이하예요(모델마다 다름, 처음 저장할 때는 조금 더 비쌈).

단, 시스템 프롬프트 같은 앞부분이 한 글자라도 바뀌면 캐시가 깨져요. 고정할 건 앞에, 바뀌는 건 뒤에.

요금이 이상하면 로그에서 요청마다 input_tokens와 cache_read_input_tokens부터 확인하세요.

  9. 앞부분이 바뀌면 캐시가 깨진다
  10. 요금이 이상하면 입력 토큰부터

메모 · 영상에 다 못 넣은 것

캐시는 오래 안 남아요

앤트로픽 기본은 5분(쓸 때마다 다시 늘어남), 1시간짜리는 저장 값이 더 비쌈

그래서 사람이 한참 쉬었다 이어 쓰는 챗봇이면 캐시가 식어서 다시 비싸질 수 있음

요청 로그의 cache_read_input_tokens가 0으로 떨어지는 구간을 찾아보세요
