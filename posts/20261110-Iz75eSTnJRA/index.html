같은 시험인데 비용 28배, Claude Fable 5.2 vs GPT-6.1 Terra

Same test, 28x the cost: Claude Fable 5.2 vs GPT-6.1 Terra

가격표는 8배 차이인데, 같은 시험을 풀게 하면 실제 비용은 28배까지 벌어져요. Fable 5.2가 오래 생각하면서 출력 토큰을 2.8배 더 쓰거든요. 대신 지능 지수는 65 대 51로 14점 높아요.

그래서 실무에서는 하나를 고르지 않고, 라우터를 둬서 쉬운 일은 싼 모델로, 어려운 일만 비싼 모델로 보내요.

  • Claude Fable 5.2 (Anthropic, 2026.11.9): 백만 토큰당 입력 8달러, 출력 40달러
  • GPT-6.1 Terra (OpenAI, 2026.10.26): 백만 토큰당 입력 1달러, 출력 5달러
  • Artificial Analysis 지능 지수 v5: Fable 5.2(Max) 65점, 과제당 26.54달러, 출력 토큰 2.75억 / Terra(Max) 51점, 과제당 0.96달러, 출력 토큰 9,940만
