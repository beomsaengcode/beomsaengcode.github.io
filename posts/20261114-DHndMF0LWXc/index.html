글을 한 글자도 안 쓰는 AI, Gemini Decisions API

An AI that writes nothing: Gemini Decisions API

구글이 글을 쓰지 않는 모델 Gemini Decision 1을 냈어요. 답을 한 토큰씩 쓰는 대신, 정해 둔 보기마다 확률 점수만 한 번에 매겨요.

그래서 출력 토큰은 0원, 입력만 백만 토큰당 0.10달러이고, 응답은 0.15~0.25초예요. 입력 하나에 질문을 최대 1,000개까지 한 번에 물을 수 있어요.

치킨집 문의를 배달·환불·메뉴로 나누고, 확신 점수가 낮으면 사람 상담원에게 넘기는 식으로 써요. 고르는 일은 Decision에, 글 쓰는 일은 일반 LLM에.

  • 가격: 입력 100만 토큰당 0.10달러, 출력 토큰 과금 없음
  • 응답: 끝에서 끝까지 150~250ms
  • 질문: 입력 하나(최대 256K 토큰)에 최대 1,000개 (예/아니오, 객관식, 루브릭 점수)
  • 구글 발표: 같은 평가 모음 기준 Gemini 3.5 Flash-Lite보다 약 5배 저렴

출처: Google DeepMind 공식 발표 "Gemini Decisions API" (2026.11.11)
