8 resilience patterns to name when you ask AI for code

AI한테 "서버 튼튼하게 해 줘"라고 하면 매번 다른 코드가 나와요. 패턴 이름으로 시키면 정확해져요. 저장해 두고 쓰세요.

1. 재시도 + 백오프 (retry with exponential backoff): 실패하면 1초, 2초, 4초 쉬며 다시

2. 타임아웃 (timeout): 느리면 정해진 시간에 끊고 대체 응답

3. 서킷 브레이커 (circuit breaker): 계속 실패하면 잠시 차단 (CLOSED → OPEN → HALF-OPEN)

4. 레이트 리밋 (rate limiting, token bucket): 정해진 양만 받고 넘치면 429

5. 멱등 키 (idempotency key): 같은 결제가 두 번 와도 한 번만 처리

6. 폴백 (fallback): 기본이 죽으면 캐시 같은 예비로 응답

7. 메시지 큐 (message queue): 몰리면 줄 세워 차례로 처리

8. 캐시 (cache): 자주 찾는 건 가까이 두기
